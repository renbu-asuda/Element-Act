# エレメント・アクト（Element-Act）

エレメント・アクトのカードをブラウザで作成できるサイトです。

## カードメーカーを開く

**[EAカードメーカーを開く](https://renbu-asuda.github.io/Element-Act/)**

- 現在の収録版：**v57**
- [カードメーカーのHTML](index.html)
- [HTMLをダウンロード](https://raw.githubusercontent.com/renbu-asuda/Element-Act/main/index.html)して、ブラウザで開くこともできます。リンク先ではブラウザの「名前を付けて保存」などを使用してください。

> 公開URLが404になる場合は、下記の「GitHub Pagesの公開設定」を確認してください。初回の公開や更新の反映には時間がかかる場合があります。

## 使い方

1. カード名・文明・コスト・能力文などを入力します。
2. イラストを読み込み、位置や拡大率、文字、フレームを調整します。
3. プレビューを確認し、「PNGで保存」で完成画像を書き出します。
4. あとから編集する場合は、「編集データを保存」で画像を含むJSONファイルを保存してください。「編集データを読込」で復元できます。

## 主な機能

- 単面カード、ツインパクト、横向きのフィールド・オーラの作成
- フレーム、文字サイズ、イラストの位置・拡大率の調整
- フルサイズイラストと、能力文の黒縁・半透明背景の調整
- PNG書き出し、編集データの保存・読込
- ブラウザ内の自動保存、カード棚、編集履歴
- 複数カードの一括書き出し、A4印刷用データの作成

編集内容の自動保存は、使用している端末・ブラウザ内に保存されます。端末を変更する場合やバックアップには、編集データのファイル保存を利用してください。

## GitHub Pagesの公開設定

リポジトリ管理者が次の設定を行うと、上記の公開URLから利用できます。

1. リポジトリの **[Settings → Pages](https://github.com/renbu-asuda/Element-Act/settings/pages)** を開きます。
2. **Build and deployment → Source** で **Deploy from a branch** を選択します。
3. **Branch** を **main**、フォルダを **/ (root)** にして **Save** を押します。
4. デプロイ完了後、**https://renbu-asuda.github.io/Element-Act/** を開きます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | EAカードメーカー v57。本体のHTML・CSS・JavaScriptを含みます。 |

カードメーカーを更新する際は、`index.html` を新しい版に差し替えてください。公開URLは同じまま利用できます。
